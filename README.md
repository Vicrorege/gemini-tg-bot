# 🤖 Gemini Telegram Bot (Google Gemini / Antigravity API + Web Intelligence)

Полнофункциональный Telegram-бот на базе **Google Gemini** через **Antigravity API** с интеллектуальным **веб-поиском в реальном времени**, автоматическим чтением ссылок, изолированными сессиями диалогов, сжатием контекста, стримингом ответов и мультимодальностью (Vision + документы).

---

## ✨ Ключевые возможности

1. **🌐 Интеллектуальный поиск в интернете и чтение сайтов (Web Intelligence)**
   - **Автоматический поиск (Auto Grounding)**: бот сам определяет, когда требуются актуальные факты, новости, релизы, музыкальные треки, курсы или документация, ищет информацию в DuckDuckGo и формирует точный ответ с кликабельными источниками.
   - **Прямой поиск (`/search <запрос>`)**: принудительный поиск в сети по любой теме.
   - **Автоматический парсинг ссылок**: если отправить в сообщении URL (статью на Хабре, документацию, GitHub), бот скачает страницу, очистит ее от лишнего HTML-кода и ответит с учетом её содержания.
   - **Гибкие режимы поиска (`/web`)**: интерактивное меню переключения (`Авто`, `Всегда включен`, `Отключен`).

2. **🗂 Полноценная система сессий (как в ChatGPT / Gemini)**
   - Каждая тема или проект ведутся в отдельной изолированной ветке диалога.
   - Команды `/new`, `/sessions` с удобным интерактивным Inline-меню для пагинации и переключения.
   - Автоматическая генерация емкого заголовка диалога по смыслу первого сообщения.
   - Переименование (`/rename`), очистка (`/clear`) и удаление сессий (`/delete`).

3. **🧠 Умное сжатие контекста (Context Compression)**
   - Автоматическая суммаризация истории при превышении лимита токенов (`MAX_CONTEXT_TOKENS`).
   - Защищенное окно последних $N$ сообщений (`PROTECT_LAST_N_MESSAGES`) для сохранения актуальной нити беседы.
   - Предыдущие реплики аккуратно сворачиваются моделью в структурированное резюме (`session.summary`).
   - Ручной вызов сжатия командой `/compress` и статистика по токенам через `/stats`.

4. **⚡️ Стриминг ответов в реальном времени**
   - Мгновенный вывод текста по мере генерации (`stream=True`).
   - Адаптивный троттлинг редактирования сообщений (`STREAM_UPDATE_INTERVAL`), предотвращающий ошибку Telegram `429 Too Many Requests`.
   - Корректный перенос и сплит длинных сообщений (> 4000 символов) без разрыва Markdown-тегов.

5. **🖼 Мультимодальность (Vision + Документы)**
   - **Фото и скриншоты**: анализ изображений через Vision API (`image_url` в Base64).
   - **Документы и файлы**: чтение PDF (через `pypdf`), текстовых файлов и исходного кода (`.py`, `.js`, `.json`, `.md`, `.txt`, `.yaml`, `.csv`).

6. **🛡 Ограничение доступа (Whitelist TG ID)**
   - Защита от несанкционированного расхода лимитов и квот.
   - Бот отвечает только пользователям из списка `ALLOWED_TELEGRAM_IDS`.

## 🛠 Стек технологий

* **Python 3.11+**
* **`aiogram 3.x`** — современный асинхронный Telegram-фреймворк.
* **`openai` (AsyncOpenAI)** — клиент для взаимодействия с OpenAI-совместимым API Antigravity.
* **`ddgs` & `beautifulsoup4`** — асинхронный поиск в интернете и парсинг веб-страниц.
* **`aiosqlite`** — асинхронная база данных SQLite с поддержкой WAL-режима.
* **`pydantic-settings`** — строгая типизация и валидация конфигурации из `.env`.
* **`tiktoken`** & **`pypdf`** — подсчет токенов и парсинг документов.

## 📖 Руководство по подключению к API Antigravity

**Antigravity** предоставляет высокопроизводительный доступ к линейке моделей Google Gemini с поддержкой OpenAI-совместимого протокола чат-комплишенов (`/v1/chat/completions`).

### 1. Доступные модели и пул выбора

Пул доступных для переключения моделей настраивается в `.env` переменной `AVAILABLE_MODELS` через запятую:
* `agy/gemini-3.7-flash-high` — новейшая модель Gemini с высокой скоростью генерации и глубоким логическим мышлением.
* `agy/gemini-3.1-pro-high` — мощная reasoning-модель для сложных аналитических, архитектурных и комплексных задач.

Пользователь может в любой момент нажать команду `/model` прямо в чате Telegram и мгновенно переключить активную модель через интерактивное Inline-меню.

### 2. Настройка подключения в `.env`

Для работы бота укажите ваш базовый URL, API-ключ и пул моделей:

```ini
# Базовый адрес API Antigravity
OPENAI_BASE_URL=https://your-antigravity-endpoint.com/v1

# API-ключ доступа к сервису
OPENAI_API_KEY=your_antigravity_api_key

# Модель по умолчанию
DEFAULT_MODEL=agy/gemini-3.7-flash-high

# Модель для быстрого анализа поисковых интентов
ROUTER_MODEL=agy/gemini-2.5-flash

# Пул моделей для интерактивного выбора в Telegram через /model
AVAILABLE_MODELS=agy/gemini-3.7-flash-high,agy/gemini-3.1-pro-high
```

## 🚀 Установка и быстрый старт

### 1. Клонирование репозитория

```bash
git clone https://github.com/Vicrorege/gemini-tg-bot.git
cd gemini-tg-bot
```

### 2. Конфигурация окружения

Скопируйте пример файла конфигурации:

```bash
cp .env.example .env
nano .env
```

Заполните обязательные параметры:
- `BOT_TOKEN` — токен вашего бота от [@BotFather](https://t.me/BotFather).
- `ALLOWED_TELEGRAM_IDS` — ваш числовой Telegram ID (узнать можно в [@userinfobot](https://t.me/userinfobot)).
- `OPENAI_BASE_URL` и `OPENAI_API_KEY` — реквизиты доступа к API Antigravity.

### 3. Варианты запуска

#### Вариант А: Запуск через Docker Compose (Рекомендуется)

```bash
docker compose up -d --build
```

Просмотр логов:
```bash
docker compose logs -f
```

#### Вариант Б: Локальный запуск через `uv` или `venv`

```bash
# Создание окружения и установка зависимостей через uv:
uv venv
source .venv/bin/activate
uv pip install -r requirements.txt

# Либо через стандартный pip:
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

# Запуск бота:
python bot/main.py
```

#### Вариант В: Запуск как Systemd-сервис (Linux)

1. Отредактируйте пути в `gemini-tg-bot.service` под ваш сервер.
2. Скопируйте сервис и запустите его:

```bash
sudo cp gemini-tg-bot.service /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl enable --now gemini-tg-bot
sudo systemctl status gemini-tg-bot
```
